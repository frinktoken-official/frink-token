Project Overview

Frink Token (FRINK) is an experimental ERC-20 on the Polygon PoS Network with a fixed supply of 10 billion tokens.

Live uses are transfer and swap on this page. Polygon transfer fees are typically well under $0.001. That is a network property, not a FRINK app.

What FRINK does

FRINK is a standard ERC-20. Today it can be used for:

  • Transfer — send FRINK to another Polygon wallet, on this page
  • Swap — trade FRINK/POL through the locked QuickSwap V3 pool, on this page (thin liquidity)
